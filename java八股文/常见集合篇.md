# 常见集合篇

## 一、导学

本篇主要涉及 List 和 Map 相关的高频面试题，重点包括：

- ArrayList
- LinkedList
- HashMap
- ConcurrentHashMap

![[常见集合.png]]

- ArrayList 底层实现是数组
- LinkedList 底层实现是双向链表
- HashMap 的底层实现使用了众多数据结构，包含了数组、链表、散列表、红黑树等

在讲解这些集合之前，会先讲解数据结构和算法复杂度分析，理解了数据结构的特点之后，熟悉集合就更加简单了。

## 二、算法复杂度分析

学习算法复杂度的好处：

- 指导你编写出性能更优的代码
- 评判别人写的代码的好坏

算法复杂度分析包含两个内容：时间复杂度和空间复杂度。通常说的复杂度都是指时间复杂度。

### 1. 时间复杂度

时间复杂度分析简单来说就是评估代码的执行耗时。看下面的代码：

```Java
/**
 * 求1~n的累加和
 * @param n
 * @return
 */
public int sum(int n) {
   int sum = 0;
   for ( int i = 1; i <= n; i++) {
     sum = sum + i;
   }
   return sum;
}
```

分析过程如下：

1. 假如每行代码的执行耗时一样：1ms
2. 分析这段代码总执行多少行？3n+3
