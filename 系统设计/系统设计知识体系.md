这份 **系统设计知识体系** 面向后端学习、工程实践和面试复习，围绕“把业务需求拆成稳定、可维护、可扩展的工程方案”整理本站系统设计相关文章。

系统设计不是只背秒杀、短链、Feed 流这类场景题。真正落到后端开发里，还需要理解 API 设计、代码质量、设计模式、框架原理、认证授权、数据安全、定时任务和实时消息推送等基础能力。

如果你时间有限，建议先看 [系统设计常见面试题总结](https://javaguide.cn/system-design/system-design-questions.html) ，快速建立高频问题清单；如果想系统补基础，可以按下面的阅读顺序推进。

## 适合谁看

- 正在系统学习后端系统设计的开发者。
- 准备校招、社招、中大厂后端面试的同学。
- 想把“会写业务代码”进一步提升到“能设计模块和方案”的工程师。
- 已经接触 Spring、MyBatis、权限系统、定时任务等技术，但缺少系统化梳理的读者。

## 学习重点

- 系统设计面试中，如何从需求澄清、核心流程、数据模型、接口设计、扩展性和风险点组织答案？
- RESTful API、命名、重构、单元测试这些工程基础，如何影响长期维护成本？
- 设计模式不是背 UML 图，而是理解常见变化点如何被封装。
- Spring、MyBatis、Netty 等框架分别解决了哪些工程复杂度？
- 认证授权、JWT、SSO、权限系统和数据安全分别覆盖安全链路的哪些部分？
- 定时任务和实时消息推送在生产环境里有哪些选型和稳定性问题？

## 建议阅读顺序

1. [系统设计常见面试题总结](https://javaguide.cn/system-design/system-design-questions.html) ：先建立系统设计场景题和高频问题清单。
2. [系统设计基础专题](https://javaguide.cn/system-design/basis/) ：补齐 RESTful API、软件工程、代码命名、代码重构和单元测试。
3. [设计模式常见面试题总结](https://javaguide.cn/system-design/design-pattern.html) ：理解常见设计模式适合解决哪些变化点。
4. [Spring & Spring Boot 专题](https://javaguide.cn/system-design/framework/spring/) ：掌握 IoC、AOP、事务、自动装配、常用注解和框架设计模式。
5. [认证授权与数据安全专题](https://javaguide.cn/system-design/security/) ：系统理解认证授权、JWT、SSO、权限系统、加密、脱敏和数据校验。
6. 再根据项目需要阅读 [Java 定时任务详解](https://javaguide.cn/system-design/schedule-task.html) 和 [Web 实时消息推送详解](https://javaguide.cn/system-design/web-real-time-message-push.html) 。

## 核心文章

### 系统设计与工程基础

- [系统设计常见面试题总结](https://javaguide.cn/system-design/system-design-questions.html) ：覆盖短链系统、秒杀系统、海量数据处理等系统设计场景题。
- [系统设计基础专题](https://javaguide.cn/system-design/basis/) ：从 RESTful API、软件工程讲到代码命名、代码重构和单元测试。
- [RestFul API 简明教程](https://javaguide.cn/system-design/basis/RESTfulAPI.html) ：理解资源建模、HTTP 方法、状态码和接口设计规范。
- [代码重构指南](https://javaguide.cn/system-design/basis/refactoring.html) ：理解代码坏味道、重构原则和常见重构手法。
- [单元测试到底是什么？应该怎么做？](https://javaguide.cn/system-design/basis/unit-test.html) ：理解单元测试、Mock、Stub、测试金字塔和 JUnit 基础。
- [设计模式常见面试题总结](https://javaguide.cn/system-design/design-pattern.html) ：梳理单例、工厂、代理、责任链、策略、观察者等常见设计模式。

### 常用框架

- [Spring & Spring Boot 专题](https://javaguide.cn/system-design/framework/spring/) ：串联 Spring、Spring MVC、Spring Boot 的常见问题。
- [Spring常见面试题总结](https://javaguide.cn/system-design/framework/spring/spring-knowledge-and-questions-summary.html) ：覆盖 IoC、AOP、Bean 生命周期、依赖注入等核心问题。
- [SpringBoot常见面试题总结](https://javaguide.cn/system-design/framework/spring/springboot-knowledge-and-questions-summary.html) ：覆盖自动配置、Starter、配置加载和 Actuator 等问题。
- [MyBatis常见面试题总结](https://javaguide.cn/system-design/framework/mybatis/mybatis-interview.html) ：理解 `#{}` 、 `${}` 、动态 SQL、缓存、分页插件和 Mapper 映射。
- [Netty常见面试题总结](https://javaguide.cn/system-design/framework/netty.html) ：了解高性能网络编程、Reactor 模型、事件循环和 ChannelPipeline。

### 认证授权与数据安全

- [认证授权与数据安全专题](https://javaguide.cn/system-design/security/) ：围绕认证授权、JWT、SSO、权限系统、加密、脱敏和数据校验展开。
- [认证授权基础概念详解](https://javaguide.cn/system-design/security/basis-of-authority-certification.html) ：理解认证、授权、Session、Token、OAuth2 等基础概念。
- [JWT 基础概念详解](https://javaguide.cn/system-design/security/jwt-intro.html) ：理解 JWT 组成、签名、工作流程和登录鉴权场景。
- [权限系统设计详解](https://javaguide.cn/system-design/security/design-of-authority-system.html) ：理解 RBAC 权限模型和权限系统设计。
- [常见加密算法总结](https://javaguide.cn/system-design/security/encryption-algorithms.html) ：理解对称加密、非对称加密、哈希算法和常见应用场景。
- [数据脱敏方案总结](https://javaguide.cn/system-design/security/data-desensitization.html) ：理解常见敏感数据脱敏规则和工程实现。

### 任务调度与消息推送

- [Java 定时任务详解](https://javaguide.cn/system-design/schedule-task.html) ：梳理 Timer、ScheduledThreadPoolExecutor、DelayQueue、时间轮、Spring @Scheduled 和分布式任务调度框架。
- [Web 实时消息推送详解](https://javaguide.cn/system-design/web-real-time-message-push.html) ：理解短轮询、长轮询、SSE、WebSocket 和消息推送选型。
- [J2EE 基础知识](https://javaguide.cn/system-design/J2EE%E5%9F%BA%E7%A1%80%E7%9F%A5%E8%AF%86.html) ：回顾 Servlet、请求转发与重定向、Session 和 Cookie 等 Java Web 基础。
